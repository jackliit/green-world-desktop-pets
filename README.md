## 使用說明

- 只支援 Windows 10／11，下載後雙擊就能用，不用安裝。
- 拖曳可以移動，滾輪調整大小，滑過身體可以撫摸，右鍵打開選單（餵食、朋友來訪、知識小卡等）。
- 更新前請先結束舊版：在寵物身上按右鍵 → 結束。
- 第一次開啟時 Windows 可能跳出 SmartScreen 警告，請按「其他資訊」→「仍要執行」。每個 Release 都附有 SHA-256 可以比對。

## How to use

- Windows 10 / 11 only. Double-click the downloaded file — no installation needed.
- Drag to move, scroll to resize, hover over its body to pet it, right-click for the menu (feeding, friend visits, fun-fact cards…).
- Close the old version before updating: right-click the pet → Quit.
- If SmartScreen warns you the first time, click “More info” → “Run anyway”. Each release lists the file’s SHA-256.
